# KuroMon

Windows 11 用のハードウェア監視ソフトです。

## 概要

KuroMon は、CPU や GPU の温度、使用率などを 1 秒ごとに表示するソフトです。

- CPU 温度、GPU 温度、GPU 使用率、メモリ使用率を、大きな数字と直近 60 秒のグラフで表示します。
- タスクバーの通知領域（画面右下）に常駐し、選んだ値をアイコンに数字で表示します。
- CPU、GPU、メモリ、マザーボード、ディスプレイの詳しい情報を確認できます。

## 動作環境

- Windows 11（64 ビット版）
- 管理者権限（温度センサーの読み取りに必要です）
- CPU 温度の表示には、PawnIO ドライバーが必要です（「CPU 温度が表示されない場合」を参照してください）。

## インストールと起動

- インストーラー版は、`KuroMon-Setup-v1.3.0.exe` を実行し、画面の案内に従ってインストールしてください。
- ポータブル版は、`KuroMon.exe` を任意のフォルダー（例: `C:\Tools\KuroMon`）に置いて実行してください。

どちらも、起動時に「ユーザー アカウント制御」の確認が表示されます。「はい」を選んでください。

## 使い方

### メイン画面

起動するとダッシュボードが表示されます。CPU 温度、GPU 温度、GPU 使用率、メモリ使用率を、値に応じて色分けして表示します。

| 状態 | 温度 | 使用率 |
|---|---|---|
| 正常 | 70 °C 未満 | 75 % 未満 |
| 注意 | 70 °C 以上 | 75 % 以上 |
| 危険 | 85 °C 以上 | 90 % 以上 |

ほかのタブでは、CPU、GPU、メモリ、マザーボード、ディスプレイの詳しい情報を確認できます。ディスプレイのタブでは、接続中のすべてのモニターについて、解像度、現在のリフレッシュレート、選択できる最大のリフレッシュレート、接続方式を表示します。表示した情報はコピーできます。

### 通知領域のアイコン

- アイコンには、選んだ値（初期設定は CPU 温度）を数字で表示します。背景の色は、正常のときは緑、注意のときは黄、危険のときは赤になります。
- アイコンにマウスを合わせると、CPU、GPU、メモリの値をまとめて表示します。
- アイコンをクリックすると小さなパネルが開き、ダブルクリックするとメイン画面が開きます。
- 右クリックのメニューから、アイコンに表示する値の変更、自動起動の切り替え、終了などができます。

ウィンドウの「×」ボタンを押しても KuroMon は終了せず、通知領域に戻ります。終了するときは、通知領域のアイコンを右クリックして「終了」を選んでください。

Windows 11 では、新しいアイコンは通知領域の「^」の中に隠れて表示されます。常に表示するには、Windows の「設定」→「個人用設定」→「タスクバー」→「その他のシステム トレイ アイコン」で KuroMon をオンにしてください。

## 主な機能

- 温度と使用率の表示（1 秒ごとに更新、直近 60 秒のグラフ付き）
- 通知領域への常駐と、アイコンへの数値表示
- ハードウェアの詳しい情報の表示とコピー
- 高温のお知らせ（CPU または GPU が 85 °C 以上の状態が 10 秒続いたときに通知します。同じ通知は 10 分間出しません）
- Windows の起動時に自動で起動（初期設定で有効）
- ダークテーマとライトテーマの切り替え
- 新しいバージョンのお知らせと自動更新（起動時と 6 時間ごとに確認し、更新するかどうかはその都度選べます）

これらの設定は、メイン画面の「設定」タブで変更できます。

## 自動起動について

自動起動は、Windows のタスク スケジューラに登録して行います。サインインの 10 秒後に、通知領域に常駐した状態で起動します。この方法で起動したときは、「ユーザー アカウント制御」の確認は表示されません。

ポータブル版の `KuroMon.exe` を別のフォルダーへ移動した場合は、移動先から一度起動してください。登録が新しい場所に更新されます。

## CPU 温度が表示されない場合

CPU 温度の読み取りには、PawnIO ドライバーを使用しています。PawnIO がインストールされていないときは、CPU 温度が「N/A」と表示され、画面の上部に案内が表示されます。

PawnIO を [公式サイト](https://pawnio.eu/) から入手してインストールし、KuroMon を起動し直してください。

## データの保存場所

| 内容 | 場所 |
|---|---|
| 設定 | `%LOCALAPPDATA%\KuroMon\settings.json` |
| ログ（14 日間保存） | `%LOCALAPPDATA%\KuroMon\logs\` |

## 注意事項

- このソフトにはコード署名をしていないため、初めて実行したときに「Windows によって PC が保護されました」と表示されます。「詳細情報」をクリックし、「実行」を選ぶと起動できます。
- メモリの温度は表示していません。
- 取得できる値は、お使いのパソコンの部品やドライバーによって異なります。

## アンインストール

- インストーラー版は、Windows の「設定」→「アプリ」→「インストールされているアプリ」から KuroMon を選び、アンインストールしてください。自動起動の登録も一緒に削除されます。
- ポータブル版は、「設定」タブで自動起動をオフにしてから、`KuroMon.exe` を削除してください。

どちらの場合も、`%LOCALAPPDATA%\KuroMon` の設定とログは残ります。不要な場合は手動で削除してください。
