# KuroMon

Windows 11 のためのハードウェアモニターです。CPU・GPU・メモリの使用率と温度を、ゲーム中でも視線を動かさずに確認できます。

タスクマネージャーは情報が多すぎて、温度は出ません。KuroMon が出すのは、遊んでいる最中に知りたい数字だけです。1 秒ごとに更新し、ふだんはタスクバーの通知領域に CPU 温度を数字で置いておきます。

**[最新版をダウンロード](https://github.com/Irony-s9c/KuroMon-releases/releases/latest)**

| ファイル | 内容 |
|---|---|
| `KuroMon-Setup-vX.Y.Z.exe` | インストーラー版。`C:\Program Files\KuroMon` に入り、スタートメニューに登録されます |
| `KuroMon.exe` | ポータブル版。好きなフォルダに置いてそのまま起動できます。.NET ランタイムも同梱しています |

| | |
|---|---|

## 画面

**ダッシュボード**　CPU・GPU・RAM を 3 枚のパネルに並べます。使用率と温度は大きな数字で、状態は色と文字の両方で示します。直近 60 秒のグラフでは、使用率を塗り、温度を破線で重ねています。CPU の最大クロック、GPU の VRAM、メモリの使用量（GB）も同じパネルに出ます。

**ハードウェア**　CPU・GPU・ディスプレイ・メモリ・マザーボードの型番や仕様。接続中のモニターすべての解像度、現在と最大のリフレッシュレート、接続方式も確認できます。表示した値はそのままコピーできます。

状態の目安は次のとおりです。

| 状態 | 温度 | 使用率 |
|---|---|---|
| 正常 | 70 °C 未満 | 75 % 未満 |
| 注意 | 70 °C 以上 | 75 % 以上 |
| 危険 | 85 °C 以上 | 90 % 以上 |

## ゲーム中に見る

**オーバーレイ**（v1.5.0 から）　CPU・GPU・RAM の使用率と温度を、画面の端に細いバーで常に表示します。ゲームのフォーカスは奪いません。ドラッグで好きな位置に置けて、次回もその位置で開きます。右クリックで「クリックを透過する」に切り替えると、バーの上でもゲームを操作できます。

- ウィンドウ / ボーダーレス表示のゲームの上に出ます。排他的フルスクリーンでは隠れるので、ゲーム側をボーダーレスにしてください。
- OBS などの「ゲームキャプチャ」には映りません。配信画面に載せたくない場合もそのまま使えます。

**通知領域**　タスクバー右下に、選んだ値（既定は CPU 温度）を数字で表示します。背景は正常なら緑、注意で黄、危険で赤に変わります。マウスを乗せると全体の値、クリックで小さなパネル、ダブルクリックでメイン画面が開きます。

**高温の通知**　CPU か GPU が 85 °C 以上のまま 10 秒続いたら知らせます。同じ通知は 10 分間出しません。

## メモリの解放（v1.5.0 から）

ゲームを起動したまま、裏で動いているブラウザーやチャット、ランチャーが抱えているメモリを手放させ、ゲームがすぐ使える空きを増やします。

- 解放するのはあなたのユーザーで動いているバックグラウンドのアプリだけです。前面のゲーム、OBS などの配信ソフト、Windows のシステムプロセス、指定した「解放しないアプリ」には触れません。
- 縮めたメモリは捨てるわけではありません。そのアプリが必要とすれば自動で戻ります。
- **自動モード**をオンにすると、全画面（ボーダーレスを含む）のアプリが前面にあり、メモリ使用率が設定値（既定 80 %）を超えたときに自動で実行します。間隔は最短 3 分。ゲームの邪魔をしないよう、自動実行では通知を出しません。結果はアプリ内とログで確認できます。

メモリに余裕がある PC では、ほとんど差は出ません。短い間隔で繰り返すと、逆に読み戻しで重くなることがあります。

## 起動と常駐

- Windows へのサインイン後、10 秒で通知領域に常駐した状態で起動します（タスクスケジューラ経由なので、毎回の UAC 確認は出ません）。設定でオフにできます。
- ウィンドウの × では終了せず、通知領域に戻ります。終了は通知領域アイコンの右クリックメニューから。
- Windows 11 では、新しいアイコンは「^」の中に隠れます。常に見せるには「設定」→「個人用設定」→「タスクバー」→「その他のシステム トレイ アイコン」で KuroMon をオンにしてください。

## アップデート

起動時と、その後 6 時間ごとにこのリポジトリの最新リリースを確認します。新しいバージョンがあれば「アップデートする / しない」を選べます。「アップデートする」を選ぶと、ダウンロード、差し替え、再起動まで自動で済みます。
「しない」を選んだバージョンは、次からは自動では表示しません。

## CPU 温度が「N/A」になるとき

CPU 温度の読み取りには PawnIO ドライバーを使います。

- インストーラー版（v1.4.0 から）は、未導入なら一緒にインストールします。
- ポータブル版で「N/A」と出る場合は、画面上部の案内か、設定タブの「PawnIO をインストール」から導入できます。ドライバーは KuroMon に同梱しているので、別にダウンロードする必要はありません。
- PawnIO は他のアプリと共有されることがあるため、KuroMon をアンインストールしても残します。

メモリの温度は、温度センサー付きの DDR4 / DDR5 モジュールでのみ表示されます。

## データの場所

| ファイル | 場所 |
|---|---|
| 設定 | `%LOCALAPPDATA%\KuroMon\settings.json` |
| ログ（14 日間保持） | `%LOCALAPPDATA%\KuroMon\logs\` |

## インストール時の警告について

コード署名をしていないため、初回は「Windows によって PC が保護されました」と表示されます。「詳細情報」→「実行」で進めます。

## アンインストール

インストーラー版は「設定」→「アプリ」→「インストールされているアプリ」から削除できます。自動起動の登録も一緒に消えます。
ポータブル版は、設定で自動起動をオフにしてから exe を削除してください。

## 更新履歴

- **v1.5.0**　ダッシュボードを 3 パネルに作り直し。オーバーレイ、メモリ解放（手動 / 自動）を追加。ハードウェアの詳細を別タブに分離。
- **v1.4.0**　CPU 温度用の PawnIO ドライバーを同梱し、インストーラーとアプリ内から導入できるように。
- **v1.3.0**　アップデート確認の状態表示と、失敗時の自動再試行を追加。
- **v1.2.0**　設定タブ、高温の通知、定期的なアップデート確認、インストーラーを追加。
- **v1.1.0**　通知領域への常駐と数値表示、自動起動、全モニターのディスプレイ情報を追加。
- **v1.0.0**　最初の公開版。

各バージョンの詳細は [Releases](https://github.com/Irony-s9c/KuroMon-releases/releases) を見てください。
